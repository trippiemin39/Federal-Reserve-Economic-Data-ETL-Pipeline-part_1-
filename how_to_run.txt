How to run
This project uses only Python and a few libraries. Follow these steps to run the
full pipeline from scratch.

1. Clone the repository
bashgit clone https://github.com/trippiemin39/Federal-Reserve-Economic-Data-ETL-Pipeline-part_1-.git
cd Federal-Reserve-Economic-Data-ETL-Pipeline-part_1-

2. Install the dependencies
bashpip install -r requirements.txt

3. Get a free FRED API key
Create a free account at
fred.stlouisfed.org
and request an API key.

4. Add your API key
Create a folder named API_CODE and inside it a file named FRED_API.txt.
Paste your API key into that file (nothing else, just the key).
API_CODE/
└── FRED_API.txt   <-- your key goes here
This file is listed in .gitignore, so your key stays private and is never
uploaded.

5. Run the pipeline
bashpython ETL.py
This extracts the data from FRED, transforms it, and loads everything into a
SQLite database (FREDDY.db) with the star schema. You can then query that
database to explore the data.
